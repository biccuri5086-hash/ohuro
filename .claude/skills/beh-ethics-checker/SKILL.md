# 倫理チェック（gekiyaku-todo の同名スキルをおふろクエスト向けに改変）

**入力**：チェックする施策案（仕組み・文言・報酬/ガチャ・課金導線・広告）。

**判定基準**
1. 入浴開始より、ゲーム内滞在や課金を優先させていないか（PRODUCT_REQUIREMENTS.md の目的）
2. 射幸性を煽っていないか（排出率の不透明さ、天井のない無料ガチャの過剰な誘導、有料ガチャ＝MVP では禁止）
3. 不安・自己否定・罪悪感を増幅して利用を続けさせていないか（「入らないと〜」型の脅し、連続記録の喪失を過度に強調）
4. 解約・配信停止・データ削除が難しい、または誤認させる導線になっていないか
5. 医学的効果・効果の実証・入浴の証明を示唆していないか。利用者の疾病・障害・心理状態を決めつけていないか
6. 写真撮影を、拒否しにくい形で強いていないか（人物・身体の撮影を求めない）

迷ったら「入浴開始の支援になっているか／1年後にこの人に感謝されるか」。

**出力**：`判定：OK／要修正／却下` ＋ 該当項目と修正案。OK なら1行で終える。

**やらない**：施策の新規立案
