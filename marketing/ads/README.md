## フォルダの使い分け
- `<id>/upload/`: **掲載用データ**（Meta 広告マネージャーに入稿するファイル）
  - `video_1080x1920.mp4`: 9:16、1080×1920、H.264、音声なし、約10秒
  - `thumbnail_1080x1920.png`: 静止画サムネイル
- `<id>/preview/`: **完成イメージ（確認用）**。入稿には使わない
- `<id>/copy.md`: 見出し・本文・CTA・遷移先 URL・シーン構成

すべて `scripts/ads/ads.config.mjs`（唯一の元データ）から `npm run ads:render` で生成する。手で編集しない。
生成には Playwright（Chromium）・ffmpeg・IPA ゴシックが必要（CI では生成しない）。
