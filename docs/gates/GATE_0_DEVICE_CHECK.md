# Gate 0 実機確認の手順（所有者が実施）

自動テスト（E2E）は Chromium / WebKit のエミュレーションで、実機の iOS Safari・Android Chrome とは異なります。
LP を公開環境（Vercel）に置いた後、広告配信の前に実機で確認してください。

## 準備
- テスト用のメールアドレスは、ローカル部に `+ohuro-test` を付ける（例: `yourname+ohuro-test@gmail.com`）。集計から自動で除外される
- LP は `?ohuro_test=1` を付けて開く（そのタブの計測がテスト扱いになる）
- 広告からの遷移を試す場合は、`marketing/ads/<id>/copy.md` の UTM 付き URL に `&ohuro_test=1` を付ける
