# キャラクター規格（ペット）

- 状態: **案（所有者の承認待ち）**。「現行」は `src/components/lp/Illustrations.tsx` の `PetIllustration`（viewBox 120 × 120）から測った事実
- ペットの種類・名前・設定は決まっていない（GAME_DESIGN.md にもない）。本書は**現行の 1 体の見た目**を規格にし、設定は変えない

## 1. 現行の構造（座標は viewBox 120 × 120）

| 部位 | 形 | 座標・サイズ | 塗り | 線 |
|---|---|---|---|---|
| 体 | まるいおまんじゅう形 | x 20〜100（幅 80）、y 38〜106（高さ 68）。中心 x = 60 | `#ffd6bf` | `#5b3f33` 4 |
| タオル | 頭に乗った白い布 | x 36〜84。上辺の曲線は y 約 38.5〜46、下辺の曲線は y 約 49.5〜54（上端は体の上端 y 38 とほぼ同じ高さ） | `#ffffff` | `#5b3f33` 3.5 |

- 重なり順（下から）: 湯気 → 体 → タオル → 顔（目・ハイライト・ほっぺ・口）
- 手足・しっぽ・耳はない。シルエットは「丸い体 + 頭のタオル + 上に昇る湯気」

## 2. 維持するもの（キャラクターの核）

次の要素は、承認なしに変えない。

1. 体の輪郭（横幅 80 : 高さ 68 の丸みのある形）と、茶色の太い輪郭
2. 頭に乗った白いタオルと青い帯
3. 上に昇る 3 本の湯気（本数・色は変えない。形は切れを直す範囲で調整できる）
4. 点の目 + ハイライト、横長のほっぺ、小さな口の組み合わせ
5. 体の色（`#ffd6bf`）とあたたかい配色

## 3. 比率と位置の規則（案・仮）

- 顔パーツの基準線: 目の高さ y = 74、ほっぺ・口 y = 84。左右は中心 x = 60 に対して対称（±13 が目、±22 がほっぺ）
- 目の間隔は体の幅の約 33%（26 / 80）。表情で動かす範囲は上下 ±4、左右 ±3 まで（顔が崩れない範囲）
- タオルは y 38〜54 の範囲に収め、顔パーツを隠さない（目の上端 y 69.5 より上）。タオルを別の頭の衣装に替える場合も、この範囲を超えない
- 輪郭の太さは、体 4・タオル 3.5・顔の線 3（案では 4 / 3 / 3 に整理。Issue #27 で案として提示）

## 4. サイズと用途

| 用途 | 現行の viewBox | 規則（案・仮） |
|---|---|---|
| 単体・大 | 120 × 120 | 全パーツを描く。LP のファーストビューで使用 |
| アイコン・小 | 現行は 120 × 120 を縮小 | 最小表示サイズでも、目と口が見分けられること（最小の表示サイズは Issue #27 で決める） |
| 部屋の中 | 現行は 120 × 120 を 0.48 倍（ペット幅 約 38） | **簡略版を別に作らない。** 同じ正本から、縮小時の線を補正して使う（現行は口・ほっぺ・ハイライトを省略した別描画） |
