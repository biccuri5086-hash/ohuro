# デザインガイドライン

- 状態: **案（所有者の承認待ち）**。「現行」はコードから測った事実、「案（仮）」は未承認の提案

## 1. 原則

1. **全画面 2D。3D 化しない。** 奥行きは重なり順・影の帯・ずらした輪郭で表す。3D 用のパッケージ・要素は使わない（`policy-check` が 3D パッケージを禁止している）
2. **現在のデザインを出発点にする。** ペットの形・タオル・湯気、茶色の太い輪郭、あたたかい配色を維持する。変えるときは「案」として提示し、承認を得る
3. **自作の SVG を正とする。** ラスター画像・画像生成 AI の素材・外部素材は使わない
4. **開発中の表示を守る。** 未実装の機能が使えると誤認させない。画像は「開発中のコンセプトイメージ」と示す
5. **効果や安全性を絵で断定しない。** 「入浴した証明」に見える表現（認証済みの印・合格の印など）を、写真チェックに関連づけて使わない

## 3. 線・角丸・影

### 現行

- 線の太さ: `Illustrations.tsx` では 2 / 2.5 / 3 / 3.5 / 4 / 5 / 6（7 種）。ペットの体は 4、家具は 3
- 線の端・角は丸い（`strokeLinecap="round"`、`strokeLinejoin="round"`）
- UI: 角丸 `--radius 14px`、ボタンに下側へ 4px の単色の影（`box-shadow: 0 4px 0 <色>`）。ぼかしの影は使っていない

### 案（仮）

- 線は 3 段階にそろえる。基準は「キャラクター用の座標（120 × 120）での太さ」とし、縮小するときは見た目の太さが変わらないよう補正する
  - 太 4: キャラクターの外側の輪郭
  - 中 3: 家具・小物・顔の線
  - 細 2: 細部（ハイライトの縁など）
- 線は常に丸端・丸角。ぼかしの影・グラデーション・光沢は使わない（平面的な塗り）
- 影は、単色の帯（床に落ちる楕円など）か、UI の単色オフセットだけ
- ビューボックスの端から線がはみ出して切れない（現行の湯気に切れがある。README の課題 5）

## 4. 構図と余白

- キャラクターは正方形の座標（120 × 120）、部屋は横長（320 × 180）、アイコンは 48 × 48（現行）
- 案（仮）: 重要な要素はビューボックスの端から線の太さ以上離す。スマートフォン幅（360〜430 px）で、主役の絵の高さを画面の約 1/3 以内にそろえる

## 5. 倫理上の禁止事項（`beh-ethics-checker` の観点）

- 入浴しないことを責める・罰する・悲しませる表現（泣く・怒る・しょんぼりした顔など）を作らない。感情表現は「うれしい・ねむい」など、あたたかい方向に限る
- 「あと〇分で消える」のような焦らせる演出・連続記録を失う不安をあおる演出を絵・アニメーションで作らない
- 課金・ガチャの確率や価値を、絵の見せ方（大当たりの強調など）で誤認させない。有料ガチャは未承認（実装しない）
- 効果・精度を断定する図（グラフ・チェックマークの乱用）を使わない

## 6. 変更の手順

1. 変更案を画像で提示（現行との並べた比較つき）
2. 所有者が承認
3. SVG を実装し、素材台帳に記録（出所・商用利用条件）
4. 変更前後のスクリーンショット比較を添付
5. 検査（Issue #24）と Codex の素材監査（Issue #26）を通す
