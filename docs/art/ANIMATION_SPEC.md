# 表情・ポーズ・アニメーションの制作規則

- 状態: **案（所有者の承認待ち）**。現行は「表情 1 種・ポーズ 1 種・アニメーションなし」。以下は**提案（仮）**で、具体的な絵は Issue #27 でデザイン案として提示し、承認後に確定する

## 1. 表情

### 規則（案・仮）

1. 表情の種類は **最大 8 種**。同じ顔パーツ（目・ほっぺ・口）の形の差し替えだけで作る（体の形・色は変えない）
2. 表情は、動かしてよい範囲を守る（[CHARACTER_SPEC.md](CHARACTER_SPEC.md) の 3）。目の位置は基準線 y = 74 から上下 ±4、左右 ±3 まで
3. 各表情に ID・名前・使う場面・変えるパーツを定義し、見本シートに並べる（Issue #25 で撮影）
4. **罰・責める表現を作らない。** 泣く・怒る・しょんぼりなど、入浴しなかったことを責める・悲しませる顔は作らない（DESIGN_GUIDELINES.md 5）

### 候補（案。絵は未作成・未承認）

| ID（案） | 名前 | 使う場面（案） | 現行との関係 |
|---|---|---|---|
| `neutral` | ふつう | 初期・待機 | **現行の表情** |
| `happy` | うれしい | 入浴の記録・報酬の受け取り | 口を大きく、目を細く |
| `sleepy` | ねむい | 夜・待機 | 目を半分閉じる |
| `surprised` | びっくり | ガチャの演出など | 目を大きく、口を小さな丸に |
| `cozy` | ほかほか | 入浴後 | 目を細くし、ほっぺを濃く、湯気を強調 |

- 上の 5 種で足りるかは、デザイン案で確認する（上限 8 種の範囲内で増減）

## 2. ポーズ

### 規則（案・仮）

1. ポーズは、体の輪郭の「変形」ではなく、**傾き・つぶれ・のび**の範囲で作る（シルエットの核を保つ。CHARACTER_SPEC.md 2）
2. 変形の範囲: 縦のつぶれ・のびは ±10%、傾きは ±8 度まで。タオルと湯気は体に追従する
3. 手足・しっぽなど新しい部位を足す場合は、キャラクターの設定変更にあたるため、承認を得る（本規則の範囲外）

### 候補（案。絵は未作成・未承認）

| ID（案） | 名前 | 内容 |
|---|---|---|
| `stand` | たつ | **現行の正面**。基準ポーズ |
| `sit` | すわる | 少しつぶれて安定した形（部屋のソファ用） |
| `cheer` | ばんざい | わずかにのびる + 傾き（`happy` と組み合わせ） |
| `rest` | ごろん | 横に少し傾く（`sleepy` と組み合わせ） |

## 3. アニメーション

現行は **アニメーションなし**（CSS に `animation`・`@keyframes`・`transition` はない）。追加する場合の規則（案・仮）:

### 必須

1. **`prefers-reduced-motion: reduce` のときは、すべてのアニメーションを止める**（静止画で同じ情報が伝わること）。現行 CSS が止めているのは `scroll-behavior` のみなので、アニメーション追加と同時に対応を入れる
2. **点滅・明滅は禁止**（1 秒間に 3 回以上の明るさの変化を作らない）
3. 画面の操作・読み取りを邪魔しない。入力欄・ボタンのそばで動かし続けない

### 範囲（仮の値。Issue #27 の案で検証して確定）

| 種類 | 規則（案・仮） |
|---|---|
| 単発の動き | 1 回 0.2〜1.2 秒。イージングはゆるやかに（急停止しない） |
| 繰り返しの動き | 呼吸のような小さな上下（振れ幅は体の高さの 3% 以内）だけ。周期 2 秒以上。画面内に同時に動くのは 2 要素まで |
| 画面切り替え | 0.3 秒以内。画面全体の揺れ・拡大縮小を使わない |
| 演出（ガチャ等） | 3 秒以内でスキップできる。確率・結果の見え方を誤認させる動きにしない（有料ガチャは未承認で実装しない） |

### 作り方（案）

- SVG の `transform` と CSS だけで作る（外部のアニメーションライブラリ・動画・GIF を使わない）
- パーツ単位（目・口・湯気・体）で動かせるよう、正本の SVG に ID を付ける（Issue #24）
- 動きの確認は、静止フレームのスクリーンショットで行う（Issue #25）。動きの滑らかさ・実機での負荷は、実機で確認する（未検証のまま「滑らか」と報告しない）

## 4. 確認項目（制作時のチェック）

- [ ] 表情・ポーズは定義表にある ID の範囲か
- [ ] 顔パーツの移動量・体の変形量が上の範囲内か
- [ ] 罰・責める表現・焦らせる演出がないか
- [ ] アニメーションは reduced-motion で止まるか。点滅がないか
- [ ] 見本シートに並べて、他の表情・ポーズと同じキャラクターに見えるか
