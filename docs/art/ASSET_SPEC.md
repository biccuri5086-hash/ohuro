## 2. 共通規則（案・仮）

| 項目 | 規則 |
|---|---|
| 形式 | 自作の SVG。1 素材 = 1 ファイル。ラスター画像・外部参照・スクリプトなし |
| 色 | [DESIGN_GUIDELINES.md](DESIGN_GUIDELINES.md) のパレットの色だけ |
| 線 | 太 4 / 中 3 / 細 2 の 3 段階。丸端・丸角 |
| 塗り | 単色の平面。グラデーション・ぼかし・光沢なし |
| 影 | 床に落ちる単色の楕円（任意）。家具の中に影を描かない |
| サイズ（案・仮） | 1 素材の SVG は 10 KB 以下（目安。Issue #24 で検査値を確定） |
| 識別 | ファイル名と素材 ID を一致させ、素材台帳に記録（出所・制作方法・商用利用条件） |
| 似せない | 既存の作品・キャラクター・商品に似せない。参考にした絵があれば台帳に記録 |

## 3. 家具

### 現行の比率（ペット幅 = 約 38 を 1 とする）

窓 約 1.8 / 棚 約 1.8 / ソファ 約 2.5 / ラグ 約 3.6

### 規則（案・仮）

1. **大きさ**: 幅はペットの幅の 1〜4 倍。ペットより小さな小物（棚の小物）は 0.2〜0.6 倍
2. **接地**: 床に置く家具は、底の線を床の領域（y 128 より下）に置く。壁に付ける家具（窓・絵）は、床の境界線の上
3. **重なり順**: 壁掛け → 床の面（ラグなど）→ 家具（奥から手前）→ ペット。ラグはペットの下（現行はペットの後に描画している。案で整理）
4. **向き**: 正面または真横。斜めの立体（アイソメトリック）は 3D 表現にあたるため使わない
5. **色数**: 1 つの家具に使う色は、塗り 2〜3 色 + 輪郭 1 色まで
6. **ペットとの関係**: ペットが家具に重なっても顔（目・口）が隠れない（顔の領域は家具より前面）

## 4. 衣装

1. **取り付け**: [CHARACTER_SPEC.md](CHARACTER_SPEC.md) 5 のアンカーに付ける。体の形は変えない
2. **顔の領域を覆わない**: 目・ほっぺ・口（y 69〜90 付近）を隠さない。めがね等は「顔」のアンカーの範囲内に収める
3. **重なり順**: 体 → 衣装（体側）→ 顔パーツ → 衣装（顔・頭側）。タオルは現行どおり頭の衣装の 1 つとして扱う
4. **線・色**: 体と同じ線（太 4 / 中 3）とパレット。衣装は 2〜3 色 + 輪郭
5. **所持と装備**: 絵の規格ではなく、サーバー側の所持データに基づいて決める（GAME_DESIGN.md 5）。絵の取得有無で見た目を先出しして誤認させない（コンセプトイメージの表示を維持）
6. **全ペット共通の育成レベル**（GAME-1）に影響しない: 衣装の絵で成長・強さを示唆しない

## 5. 背景

1. **部屋**: 壁と床の 2 層。壁は `#fff4e4` 系の明るい暖色、床は `#e8c39a` 系。バリエーションを作る場合も、**輪郭 `#5b3f33` とのコントラスト比 3:1 以上**を保つ（現行は壁 8.76 / 床 5.76）
2. **模様**: 壁紙・床の模様は単色の幾何学形（線 2、色 1〜2 色）。細かすぎる模様（1 辺 4 未満）は使わない
3. **窓の外**: 空の単色 + 単純な雲・星のみ。昼夜は色の差し替えで表し、点滅・流れる動きを使わない
4. **UI の背景**: `--bg #fdf6ec`。文字との比は 12.71（現行）。文字の背景は 4.5:1 以上を保つ
